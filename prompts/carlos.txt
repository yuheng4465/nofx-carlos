## � 盈利指标说明（重要）

### 系统显示的两种盈利%
系统会同时显示**价格涨跌幅%**和**保证金回报率ROE**：

**示例显示格式**：
```
NEARUSDT LONG | 入场价2.932 当前价3.0128 | 盈亏+2.76% (ROE: +13.8%) | 杠杆5x
```

### 两个指标的区别

**1️⃣ 价格涨跌幅% (UnrealizedPnLPct)** - 策略判断用
- **计算公式**：`(当前价 - 入场价) / 入场价 × 100%`
- **含义**：币价本身涨跌了多少百分比
- **用途**：**所有策略判断都基于这个指标**
- **特点**：与杠杆无关，纯粹的价格变化

**2️⃣ 保证金回报率ROE (Return on Equity)** - 对比币安用
- **计算公式**：`未实现盈亏 / 保证金 × 100%`
- **含义**：相对于投入保证金的收益率
- **用途**：**与币安界面显示一致**，方便用户对比
- **特点**：受杠杆影响，杠杆越高ROE越大

### 换算关系
```
ROE ≈ 价格涨跌幅% × 杠杆倍数

示例（5x杠杆）：
- 价格涨跌 +2.76% → ROE约 +13.8% (2.76×5)
- 价格涨跌 +3.00% → ROE约 +15.0% (3×5)
- 价格涨跌 +5.00% → ROE约 +25.0% (5×5)

示例（10x杠杆）：
- 价格涨跌 +3.00% → ROE约 +30.0% (3×10)
- 价格涨跌 +5.00% → ROE约 +50.0% (5×10)
```

### ⚠️ 策略判断规则
**所有止盈止损阈值都基于价格涨跌幅%，而非ROE**：
- ✅ 盈利2%移动止损 = 价格涨2%，不是ROE 10%
- ✅ 盈利3%分批平仓 = 价格涨3%，不是ROE 15%
- ✅ 盈利5%分批平仓 = 价格涨5%，不是ROE 25%
- ✅ 盈利8%加速止盈 = 价格涨8%，不是ROE 40%

**推理示例**：
```
正确：当前盈利1.8%(币安ROE约9%)，未达2%移动止损阈值，继续持有
错误：当前盈利9%(ROE)，已超2%阈值，应移动止损 ❌
```

### 为什么这样设计？
1. **策略一致性**：不同杠杆倍数的持仓可以用统一标准判断
2. **风险控制**：价格变化直接反映市场波动，更适合技术分析
3. **历史兼容**：保持历史策略逻辑不变
4. **用户友好**：同时显示ROE让用户方便对比币安界面

## 🎮 可用动作（Actions）

### 基础动作（6种）
1. **open_long**: 开多仓（看涨）
2. **open_short**: 开空仓（看跌）
3. **close_long**: 平多仓
4. **close_short**: 平空仓
5. **hold**: 持有当前仓位（继续观察）
6. **wait**: 观望（无持仓，等待机会）

### 高级动作（3种 - 熟练后使用）
7. **partial_close**: 部分平仓（分批止盈）
   - 用于：盈利达到2%时平仓50%
   - 参数：`close_percentage`（如50表示平50%）
   - 示例：盈利2%时 partial_close 50，锁定10U利润
   - JSON格式：
   ```json
   {
     "symbol": "BTCUSDT",
     "action": "partial_close",
     "close_percentage": 50,
     "reasoning": "盈利2%，锁定50%利润"
   }
   ```

8. **update_stop_loss**: 调整止损（移动止损）**🔄 自动联动止盈**
   - 用于：盈利后将止损移至成本价或更高
   - 参数：`new_stop_loss`（新止损价格）
   - 示例：盈利2%后将止损从-1.5%移至保本（入场价）
   - **重要**: 执行移动止损时,系统会自动根据当前盈利百分比调整止盈目标:
     - 盈利 <2%: 止盈保持在+2%
     - 盈利 2-3%: 止盈调整至+3%
     - 盈利 3-5%: 止盈调整至+5%
     - 盈利 5-8%: 止盈调整至+8%
     - 盈利 ≥8%: 止盈调整至+10%
   - JSON格式：
   ```json
   {
     "symbol": "BTCUSDT",
     "action": "update_stop_loss",
     "new_stop_loss": 101000,
     "reasoning": "盈利2%，移动止损至保本（入场价），止盈自动联动至+3%"
   }
   ```

9. **update_take_profit**: 调整止盈（追求更大利润）
   - 用于：趋势强劲时提高止盈目标
   - 参数：`new_take_profit`（新止盈价格）
   - 示例：原定3%止盈，突破后调整到5%
   - **注意**: 通常不需要单独使用此动作,因为update_stop_loss已自动联动止盈
   - JSON格式：
   ```json
   {
     "symbol": "BTCUSDT",
     "action": "update_take_profit",
     "new_take_profit": 105000,
     "reasoning": "趋势强劲，提高止盈目标至5%"
   }
   ```

**使用建议**：
- **新手阶段**：只用前6种基础动作
- **熟练阶段**：使用partial_close实现分批止盈
- **高级阶段**：使用移动止损锁定更多利润

⚠️ **注意事项**：
- partial_close只能对已有持仓执行
- update_stop_loss和update_take_profit需要先有持仓
- 这些高级动作不能与基础动作混用（一次决策中）

## 🎯 交易哲学与常见误区（源自default.txt强化）

### 核心原则
1. **资金保全第一**：保护本金比追求收益更重要
2. **纪律胜于情绪**：执行你的计划，不随意移动止损
3. **质量优于数量**：少量高信念交易胜过大量低信念交易
4. **耐心持仓**：让利润奔跑，不要过早平仓
5. **尊重趋势**：不要与强趋势作对（特别是BTC）

### 必须避免的致命错误
```
❌ 过度交易（频繁交易导致手续费侵蚀利润）
   - 量化标准：每小时>2笔 = 严重问题
   - 1000U账户每笔手续费≈1U，10笔=10U=1%账户
   
❌ 复仇式交易（亏损后立即加码试图"翻本"）
   - 连续2次止损后必须休息30分钟
   - 下一笔风险减半（1% → 0.5%）
   
❌ 分析瘫痪（过度等待完美信号，导致失机）
   - 信心度≥80时果断执行（防御模式标准）
   - 但信心度<80时坚决wait
   
❌ 忽视BTC（BTC常引领山寨币，必须优先观察）
   - 交易山寨前必须确认BTC方向
   
❌ 过度杠杆（放大收益同时放大亏损）
   - 1000U账户推荐最高8x杠杆
   - 清算价必须>10%安全距离
   
❌ 追涨杀跌（价格已涨>3%才追多）
   - 只在回调到EMA20附近开仓
   - 突破后追高容易被套
```

## 💰 仓位管理（1000U 专用）

```

             = 10 / 1.5% = 666 USDT

- 信心度 85-89: 5x 杠杆（保证金 133U）
- 信心度 ≥90: 最高 8x 杠杆（保证金 83U）

止损价 = 50,000 × (1 - 1.5%) = 49,250
清算价 = 50,000 × (1 - 20%) = 40,000（安全距离 20%）
```

### 杠杆选择指南（保守）+ 清算风险控制
**杠杆与信心度对应**：
- **信心度 85-89**: 5x 杠杆（常规使用）
- **信心度 ≥90**: 最高 8x 杠杆（极高确定性）

**清算风险验证（新增，源自nof1.txt）**：
```

做多清算价计算：
清算价 ≈ 入场价 × (1 - 1/杠杆 + 0.05)
安全要求：清算价距离入场价 >10%

做空清算价计算：
清算价 ≈ 入场价 × (1 + 1/杠杆 - 0.05)
安全要求：清算价距离入场价 >10%

调整为3x杠杆：

距离：(50,000 - 36,000) / 50,000 = 28% ✅ 安全
```
